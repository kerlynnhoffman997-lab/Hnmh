# 赶一场中原庙会 · Hnmh

河南庙会文化交互网站，覆盖 18 个地区、19 场庙会。从省域地图进入庙会全景，再沿画面热点查看活动、人物和器物的故事。支持电脑、手机和横屏。

作品网址：<https://kerlynnhoffman997-lab.github.io/Hnmh/>

## 文件与运行

本仓库是可直接部署的静态网站，入口为 `index.html`，无需安装依赖或后端服务。HTML、JavaScript、CSS 及资源均使用相对路径，适配 GitHub Pages 的项目目录。

本地预览可在仓库目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000/`。网页需通过 HTTP 服务运行，不使用 `file://` 打开。

## 手机横竖屏

手机可直接旋转切换竖屏、横屏，无需刷新；选中的地区、场景与展开的故事保持不变。横屏首页采用文字与地图并排布局，场景工具栏和翻页栏缩短，留出更多图文阅读空间。声音设置在横屏并排显示，页面为刘海与底部手势区预留安全空间。若手机锁定了屏幕方向，请先打开系统自动旋转。

## 交互与动效

首页将庙会预览与省域地图并排呈现；地区可通过地图、下拉选择、前后按钮或“随心选一场”切换，郑州的两个案例可以分别选择。地图悬停与键盘聚焦显示当地庙会名称，点预览图或入场按钮即可进入。手机竖屏在主按钮离开可用视区时显示底部入口；横屏保持地图与预览并排。新版布局由 `home-layout.css` 管理。

选城预览在新图解码后渐变切换，连续点选只显示最后一次选择。图片前后翻页采用对应方向的短距离移动；进入小场景与故事展开时轻缓显现。相邻两幅图片会提前准备，节省流量模式和慢速连接不预取。

手机在“缩小看”和人物器物细节页可在空白画面上左右轻划换图；放大的会场仍可拖动探索，故事内滑动用于阅读。按钮、方向键及画面热点均可操作；热点支持 Tab 聚焦后 Enter 或空格进入。遵循系统“减少动态效果”偏好。

`ui-components.css` 在首页和场景 iframe 共享暖纸色、松绿与朱红组件样式，统一按钮、热点、图片翻页、故事展开及焦点状态。主要操作保留至少 44px 点击高度；紧凑页码点单独设置点击范围。导航栏高度通过 `--fair-navigation-height` 与场景布局同步，调整时应保持该文件在 `responsive.css` 之后加载。

`ui-dialogs.css` 统一分享与声音弹窗，并兼容手机安全区和横屏。复制链接显示等待、成功或手动复制提示；关闭弹窗后恢复原操作位置，延迟复制结果不会覆盖重新打开的场景。

动画使用 [Motion](https://github.com/motiondivision/motion) 的 mini 版本 14.6.0，固定为本地脚本，运行时不依赖 CDN。MIT 许可证、版本与构建来源保存在 `vendor/motion/`；`fair-motion.js` 统一处理动画取消、iframe 元素和减少动态效果。

## 发布

GitHub Pages 发布源为 `main` 分支的根目录。`.nojekyll` 保证现有静态资源直接发布。修改后推送至 `main`，Pages 会自动更新。

首页的作品二维码文件为 `assets/review-qr.svg` 与 `assets/review-qr.png`。如更换网址，需要同时更新二维码。

## 音乐与交互音效

首页与会场顶部的音符按钮可打开声音设置。首次点击“开启声音”后播放背景配乐；选地区、进入会场、切换图片、探索人物器物及展开故事均有轻量音效。音乐和音效可分别关闭、调节音量，也可一键全部静音。设置仅存于当前浏览器，切换到后台会暂停，重新打开网页需一次用户操作才能恢复播放。

`sound.js` 在宿主页面共享一个 Web Audio 引擎，避免 iframe 切换时重复播放；音频只在开启后加载。背景音乐为 48 秒原创程序合成五声调式配乐，交互音效为程序合成的拨弦和轻鼓声。两者均非庙会现场录音，素材说明见 `assets/audio/README.md`。

配乐优先加载 673 KB MP3，失败时回退至 WAV。音乐开关平滑淡入淡出，重新开启从暂停位置继续；展开故事时自动降低配乐，收起后恢复。向前与返回的提示音采用不同音型。

站内图像为 AI 概念插画；部分建筑位置、摊位邻接和人物站位经过构图补全，不代表实测地图或同一时刻的现场。
