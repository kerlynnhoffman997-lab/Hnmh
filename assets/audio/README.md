# 网站背景音乐

`fair-background.wav` 是为本网站编写的原创程序合成背景音乐，48 秒，80 BPM，D 大调五声调式，24 kHz 双声道 16-bit PCM WAV。

音乐由轻柔拨弦、少量合成笛音、低音和木质节拍组成。旋律、伴奏与音色均由确定性的 Python 程序生成，未使用第三方音乐、现成旋律、录音采样或声音字体。它是营造浏览氛围的当代配乐，不是庙会现场录音，也不代表任何地方仪式或传统曲牌。

首尾采用环形混音保留余音，可连续循环。合成脚本位于项目工作目录的 `github-pages/qa/compose-music.py`，校验记录位于同目录 `music-validation.json`。浏览器端应使用较低音量，遵循用户的声音开关；互动音效与此文件独立。

2026-10-22 更新：浏览器优先请求 `fair-background.mp3`（673,008 字节），比 WAV 母版（4,608,044 字节）减少 85.39%。MP3 解码失败时再请求 WAV；正常播放不下载两份文件。编码保持 48 秒、24 kHz 双声道，母版未改动。编码脚本与数值检查为工作目录中的 `github-pages/qa/encode-music.py`、`music-encoding-validation.json`。

离线编码工具使用 [SoundFile 0.13.1](https://github.com/bastibe/python-soundfile)（BSD-3-Clause）及其附带的 [libsndfile 1.2.2](https://github.com/libsndfile/libsndfile)（LGPL-2.1）；工具仅用于制作此原创音频，不随网站分发，也没有新增浏览器端音频依赖。

播放控制保留单一 Web Audio 音频上下文：音乐开关平滑淡入淡出，重新开启从原进度继续；展开故事时将配乐降至当前音量的 48%，收起后恢复。进入庙会、查看小场景与退回上一级采用轻柔且不同的合成提示音。初访保持静音，音效与配乐可以分别关闭或调节音量，切换到后台自动暂停。

## 泥哨互动：程序合成的艺术模拟

“循声赶会”泥咕咕样板使用短促双音，模拟轻吹泥哨的听觉印象。声音由浏览器实时生成：两个带轻微音高变化的正弦音分别使用柔和起落包络，再经过低通滤波。740 Hz 与 622 Hz 是为本作品选取的合成参数，不是对某件泥咕咕的测音结果，不用于说明真实音阶、传统曲牌或具体演奏技法。没有使用实录、录音采样或第三方音频文件。

接口为 `const stop = FairAudio.clayWhistle({pan: 0})`。它同步返回可重复调用的停止函数；`pan` 限制在 -1 至 1 之间，支持时使用共享引擎中的立体声声像节点。调用一次后，每隔约 760 毫秒轻吹一组双音，最长持续 4 秒。界面必须在松开、取消按压或失去指针捕获时调用 `stop()`，键盘按压也应在松键时停止。停止采用约 45 毫秒的平滑收尾，并在 75 毫秒内断开该段音效的连接。旧按压会被新按压替换；等待音频上下文恢复期间若已经松开，不会延后补播。

泥哨复用 `sound.js` 原有的单个 `AudioContext`，经 `effectsBus` 和 `master` 输出。总声音关闭、交互音效关闭、交互音量为零或页面在后台时不会播放，也不会自动改变用户开关。切换页面节点、打开声音设置、页面隐藏、离开页面、窗口失焦或设备方向变化都会停止当前泥哨；4 秒限制另作兜底。调用 `FairAudio.openSettings(triggerElement)` 可打开既有声音设置，由用户主动开启，关闭后将焦点交还给传入的按钮。

泥哨播放时配乐暂降至原有目标音量的 56%；它与阅读状态的 48% 降音量相乘。泥哨结束后依据当时的阅读状态恢复，因此展开故事时不会被恢复到全音量。用户的音乐、音效音量及开关设置均不被改写。

`FairAudio.readState()` 增加以下只读诊断字段：`clayWhistleAvailable`（用户开关允许且页面可见，音频上下文仍可能需要恢复）、`clayWhistleActive`、`clayWhistlePending`、`clayWhistleVoices`（当前已连接或排定的短音数量）、`clayWhistleCount`（本页实际启动次数）、`clayWhistlePan`。这些字段仅用于交互反馈和浏览器验证，不写入存储，也不发送统计数据；读取不会启动声音。
